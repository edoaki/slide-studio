# Slide Studio

研究発表のスライドをブラウザで作るローカルアプリです。原稿（`.qmd`）とスライドを並べて編集し、アニメーション付きの単一 HTML と PDF に書き出せます。描画には同梱の Pandoc を直接使うため、Quarto のインストールは不要です。

## 起動する

Python 3.13 以上と `uv` がある環境で、このリポジトリ（`slide-studio`）のディレクトリから実行します。利用者が入力するコマンドはこれだけです。

```sh
uv run slide-studio
```

Mac では Chrome の専用ウィンドウ（タブ・アドレスバーなし）で開きます。アプリ内の資料・外部リンクとスライド内のリンク先は、普段の既定ブラウザーの別タブで開き、ブックマークやログイン状態を使えます。Chrome が見つからない場合や専用ウィンドウを起動できない場合、ほかの OS では本体も既定ブラウザーで開きます。アプリの画面切り替えとスライド内の目次・文献アンカーは同じ画面で移動します。スライドの文字編集中はリンクを押しても移動しません。編集画面では左右のサイドバーを最初から表示します。上部の各ボタンで閉じられますが、編集画面を開き直すと両方とも再び表示します。専用ウィンドウの初期サイズは1800×900pxで、左右のサイドバーを開いた状態でもスライドの表示幅を確保します（実際のサイズは画面の広さに制限されます）。自動で画面を開かない場合は `uv run slide-studio --no-browser` を使います。

初回は必要なパッケージが自動で入り、ブラウザに保管場所の選択画面が開きます。［新しくフォルダを作る］か［既存のフォルダを使う］を選んでください。初期候補は `~/Slides` ですが、名前も場所も自由です。［フォルダを探す］で場所を選ぶか、パスを直接入力できます。選択後にホームが開き、次回からは同じ場所を使います。以前のデータを使う場合は、その保管フォルダ（例：`~/slide-studio`）を選びます。自動での移動・改名はしません。空の既存フォルダも選べます。

ホーム右上の［動作環境］から、書き出し用ブラウザーと AI の準備状況を確認できます。書き出し用の Chromium が未導入なら［書き出し用のブラウザを準備］を選んでください。初回の準備にはネットワーク接続が必要です。AI のログインはチャットを使うときだけ必要です（編集・書き出しには不要）。AI が未導入なら［動作環境］の各 AI の［インストール］で取得し、完了後にログインボタンを押してください。agy は PATH または `~/.local/bin/agy`・`~/.antigravity-main/agy` から探します。任意の場所を使う場合は `SLIDE_STUDIO_AGY` に実行ファイルを指定してください。チャットのモデル追加から Antigravity を選べます。

通常の URL は `http://127.0.0.1:4320` です。使用中なら次の空きポートになり、ターミナルに URL が表示されます。サーバーの準備ができ次第、画面を開きます。Slide Studio の最後のウィンドウ（通常ブラウザーではタブ）を閉じると、再読み込み用の猶予1秒のあと自動で終了します。ターミナルの `Ctrl+C` でも終了できます。`--no-browser` の場合は `Ctrl+C` で終了します。次回も同じ起動コマンドで発表一覧に戻れます。選んだフォルダが見つからないときは、もう一度選択画面を開きます。

## アプリなしで使う・フォルダを持ち運ぶ

保管フォルダには `README.md` と `build.py`、変換に必要なコードを同梱します。隠しフォルダ `.slide-studio/` も含めて全体をコピーすれば、アプリのリポジトリがなくても、テキストエディタで原稿を編集して再ビルドできます。Python 3.13 以上と `uv` が必要で、初回の依存パッケージ取得にはネットワークを使います。
旧版の保管フォルダは、内部管理フォルダ名と図・履歴内の参照を新形式へ移行してから開いてください。旧名の自動読込は行いません。


保管フォルダで実行します。

```sh
uv run build.py --list
uv run build.py 発表名 --html-only  # HTML のみ（検査なし）
uv run build.py --setup           # PDF・検査用 Chromium の初回準備
uv run build.py 発表名             # 検査して HTML と PDF を生成
```

出力は `decks/<発表名>/<発表名>.html` と `.pdf`。生成済み HTML は単一ファイルで、アプリなし・オフラインで開けます。詳細は保管フォルダの README を参照してください。

## ホームから始める

チャットの AI（スライド・下書き・テーマ）は、保管フォルダの中で、AI 本体の道具（ファイルの読み書き・コマンド・画像を見る・web 検索）で作業します。指示は保管フォルダの `AGENTS.md` と `.agents/skills/` の skill（`slide-studio-slides`・`slide-studio-memo`・`slide-studio-theme`）にあり、自分で書き換えられます。図も、スライドを作る AI が作ります。書けるのは保管フォルダの中だけで、AI 実行前の控え（`.slide-studio/snapshots/`）とチャットの記録（`.slide-studio/chat/`）には書けません。書く前には止めない代わりに、［この送信の前に戻す］で戻せます。

変更後はアプリが検査し、エラーが無ければ確認役（編集した AI とは別の会話。読むだけでファイルは変えない）が、指示どおりか・見た目・文章を確かめます。確認役が直すところを挙げると、編集した AI が同じ会話で直し、検査と確認をもう一度行います（最大3回）。確認結果は現在の要修正・エラーだけを表示し、問題なし・古くなった結果・確認中に変更されたファイルの注意は表示しません。直しきれなかった指摘はチャットに残り、［確認の指摘を添えて再依頼］で未送信の指示に加えられます。確認役の会話もタブごとに続きます。確認役の AI・思考量はチャットで設定します。入力欄のモデル名を押し、上側の［サブエージェント］を開くと［確認］の行があります。未設定なら実際に使うモデル名を薄く表示し、チャットのモデルに追従します。思考量は担当ごとに独立し、未設定ならモデルの既定値を使います。メインの思考量を変えてもサブの思考量は変わりません。Codex で作って Claude Code で確認するなど、別の AI も選べます。［確認］と［相談役］は、それぞれの行のオン・オフで切り替えられます。既定は確認がオン、相談役がオフです。オフの担当は実行せず、選んだモデルと思考量は保持します。設定はチャットのタブごとに保存し、送信開始時に確定します。以前の HTML 確認・スライド確認・下書き確認の設定は、確認に一度だけ移します。以前の会話から新方式へ移る初回は、画面の履歴を残して AI 側の会話を新しくします。ホームの［AI の担当とプロンプト］では、各担当が使う置き場の skill を確認できます。AI はタブごとに起動したままにするので、2回目からの送信は起動を待たずに始まります。10分使わなければ止め、次の送信で会話の続きから起動し直します。

- **編集を再開**：「発表」のカードを押します。表示中のページの準備ができると編集を始められ、後続ページの図は裏で読み込みます。最後に開いた発表から順に並びます。カードの上でカーソルを左右に動かすと、ページがめくれて中身を確かめられます（一度書き出した発表のみ。まだの発表は題名だけを表示します）。
- **新規作成**：［新しい発表］でタイトルと名前を入力し、［作る］を押します。作成後、そのまま編集画面が開きます。
- **複製**：［新しい発表］→［既存の発表を複製］で元の発表と新しい名前を指定します。
- **トピック**：研究の話題ごとのまとまりで、複数の発表で図を共有します。同じトピックの発表どうしでは、前に使った数式・画像も挿入の候補に出ます。ホームの下に、トピックごとの図の数と使っている発表の数を表示します。トピックを押すと、その発表・HTML・文献（`reference.bib`。一覧と詳細を Zotero のように並べ、並べ替え・絞り込みができる）を見られ、［このトピックのスライドを作る］で新しい発表を作れます。HTML は step ごとのサムネイルを横に並べ、使用中の発表も表示します。カードを押すとプレビューが開きます。［選択］ボタンかカードの長押しで複数選択に入り、［選択した HTML を削除］で未使用の HTML をごみ箱へ移せます（スクリプトや画像は残します）。［トピックを削除］で未使用のトピックを削除できます。素材・文献は `.slide-studio/trash/topics/` に移します。使用中の発表がある場合は削除できません。
- **動作環境**：右上の［動作環境］ボタンで、Pandoc・Chromium・AI の状態と保存場所を確認できます。AI のインストールとログインもここから行えます。

編集画面では、左の［テーマ］タブのテーマ名からテーマを選びます。編集欄の下の［デフォルトに戻す］では、今の内容を別のテーマとして［保存して戻す］か、［保存せずに戻す］かを選べます。保存する場合は名前を付けます。使用中のテーマはそのままデフォルトへ戻り、保存したテーマは一覧から選べます。キャンセルもでき、戻した操作は ⌘Z で取り消せます。使っていないテーマは、ホームのテーマの一覧でカーソルを合わせて出る［削除］で消せます。

テーマ変更後の下のサムネイルは、帯に見えているページから更新します。まず各ページの最初の画像を表示し、残りの段階表示を順次更新します。撮影中に帯をスクロールすると、新しく見えたページを優先します。

左の［テーマ］タブは、最初に実際のスライドを表示します。本文・強調色などの欄を押すと、その表現を使うページだけを表示し、最初の該当部分だけを控えめな細線で囲みます。スライド上の「プラス」などをクリックすると、その要素に対応する色の編集欄へスクロールして選択します。ページや段は移動せず、通常どおりブロックを選択します。太字・リンクの「強調色」と、背景付き文字の「マーカーの背景色・文字色」は別の設定です。［色分け］には［表の見出しの背景］［表の見出しの文字］［表の本文］［数式］もあります。スライドの見出しと表の見出しは独立して変更できます。表・数式を押すと対応する色欄を選び、欄を押すと該当するページを表示します。テーマ編集中は段階表示前のマーカーも着色し、原稿タブに戻ると元の段階表示に戻ります。見出しの背景色を変えても、表紙の文字色・章扉の配色は保たれます。見出しフォントを選ぶと、表示される見出しのあるページへ移動します。該当ページがない場合だけ架空の見本へ自動で切り替わり、［すべてのページ］で絞り込みを解除できます。フォントはゴシック・明朝・等幅の3種類で、名前の横にある、各書体の「ひらがな 漢字 100 English」の小さな見本（白地・紺文字）から選べます。テーマタブでも、実際のスライド上で本文の編集・削除・移動ができます。架空の見本は編集できません。実スライドを表示中も、チャットの指示先はテーマです。

テーマの設定は［本文とリンク］［色分け］［スライドの背景］［見出し］の順に並んでいます。［スライドの背景］と［見出し］は下にあり、普段は閉じています。見出しを押すと開きます。スライド上の見出しを押すと、その場で見出しを編集できます。テーマを替えても開閉はそのままです。色の見本を押すと、欄内に色見本・色面・色相バーが開きます。色面は左右で濃さ、上下で明るさを選び、矢印キーでも調整できます。カラーコードの入力にも対応します。変更はすぐに反映・自動保存され、ドラッグ1回は1回の取り消しで戻せます。×またはEscで色の設定を閉じます。見出しの装飾は［テーマの設定］［色の帯］［罫線］の見本付きボタンから選びます。選ぶと見出しのあるページへ移動し、結果を確認できます。色の帯はスライドの端まで描画します。罫線を選ぶと、その下に色・種類・太さ・長さの設定が現れ、実線・破線・点線・二重線、1〜6px、スライドの端まで／本文の幅までを選べます。［強調色］は太字、［リンク］はリンクの文字色を個別に変更します。見出しの背景と文字は独立して変更でき、文字にはグラデーションを付けません。［見出しの背景］と［見出しの文字］の色見本は実際に表示されている色に追従し、背景の選択時は見出しの領域全体を囲みます（グラデーションの背景は基準色を表示）。見出しのグラデーションは色欄右の［グラデーション］から編集を開きます。設定は左のテーマ欄に表示し、スライド上には色のポイントだけを置きます。初期表示は［背景のみ］で、［内容も表示］へ切り替えても本文・図などは選択や操作に反応しません。［初期配置］の［左右］［上下］［斜め］は位置のテンプレートです。適用後も自由にドラッグでき、再適用してもポイントの色と数を保持します。［ポイントを追加］を押して背景をクリックすると、その場所へ追加します（2〜8点）。ポイントを選ぶと左欄で色・濃さ・広がりを変更でき、3点以上なら削除できます。単色は見出しの色欄で設定します。白いチェックマークまたはEscで編集終了。追加位置の指定中のEscは追加だけを中止します。背景の空白クリックは選択解除で、編集は閉じません。開いただけでは保存内容を変更せず、操作による変更は自動保存されます。ドラッグ1回を1回の取り消しで戻せます。編集用のポイントや内容の非表示は出力に含めません。スライド全体の背景はテーマの設定を使い、編集欄には表示しません。［テーマに戻す］で元の背景・帯と装飾へ戻せます。

AI作業中でテーマを変更できない間は、テーマの一覧を無効化し、鍵アイコンと理由を表示します。作業が終わると自動で選べる状態に戻ります。

テーマを変更すると、表紙のタイトル・副題・著者名は変更先のテーマの既定位置に戻ります。文字の内容やサイズ、所属の表示設定は保たれます。

表紙のタイトル・副題は、選択済みでも文字の上からドラッグして移動できます。動かさずにもう一度クリックすると文字編集に入り、編集中のドラッグは文字の範囲選択になります。

本文・画像・囲み・列を選ぶと［ブロックのデザイン］から、枠線／上ライン／左ライン／引用／括弧／折り返しを選べます。HTML図には設定できません。単独の本文にデザインを付けると、中に要素を入れられる囲みになります。横並びの中では列にデザインを設定します。枠を付けてから横並びにしても、横並びにしてから枠を付けても「横並び → 列（枠）→ 本文」の構造になります。以前の原稿で列全体を包んでいた無名の箱は、発表を開くと列に統合します。列幅と外側余白は列、枠と内側余白は箱から引き継ぎます。列と囲みの両方に枠や影がある場合は、別々のブロックとして残します。中身が1つでも原稿欄では囲みと本文を別々に表示します。囲みを選んで［下に分割］すると中に段落を追加でき、ドラッグで枠の内外へ移動できます。選択中の見本をもう一度押すと解除します。枠線は初期状態で背景透明です。［色1］［背景］［文字］を編集でき、色・線幅・角丸・影の強さはテーマ内のデザインごとに保存します。文字を個別に色指定した箇所はその指定を優先します。線幅の初期値は3.5px、最小は1pxです。［影付き］はブロックごとに切り替え、オンのときだけ強さの設定を表示します。各テーマは用途ごとに異なる配色を持ち、見本にも実際の背景と文字色を表示します。原稿からは `::: {style="--block-design:top"}` … `:::` の短い記法で指定できます（`plain`・`top`・`left`・`quote`・`bracket`・`fold`）。影は `;--block-shadow:on` を追加します。以前の影付き・二色ラインは既存原稿の表示を維持し、新規の選択肢から外しています。［揃え］（画像は［画像の揃え］）を押すたびに、左 → 中央 → 右 → 左と切り替わります。アイコンは現在の揃えを示します。文字の編集中も同じ操作です。

発表名・トピックの名前には英小文字・数字・ハイフンを使います。トピックは最初は既定の `research` のままで使えます。

スライド上のタイトルをクリックすると、その場で文字を編集できます。Enter または Esc で編集を終え、自動保存します。タイトルのデザインはテーマの設定を保ちます。

上のバーには発表の［最初から］と［今のページから］のアイコンを常に並べています。それぞれ押すと、開始ページの最初の step から発表を始めます。ページを移動したときや HTML を開き直したときも、そのページの最初の step に戻ります。

編集画面・発表画面のスライド上では、二本指の横スクロールで前後のページへ移ります。段階表示の途中でもページ単位で移動し、1回のジェスチャーで1ページ送ります。

## 編集する

目次は原稿のブロック表示の、表紙の次にある「目次」の行のスイッチでON・OFFを切り替えます。章見出し（`#`）から自動で作成し、章がない場合は通常のページ見出し（`##`）を使います。表紙・参考文献・付録は含めません。並び方は縦並びが標準で、1列・2列の図のボタンで選べます。新しくONにすると表紙の直後に入り、OFFにしても位置と並び方を保持します。

文献タブでは一覧と詳細の境界を上下にドラッグして高さを調整できます。境界にフォーカスして上下キーでも調整できます。初期表示は一覧を広めにしています。

文献の詳細で［文献情報を編集］を押すと、年・タイトル・著者・掲載誌・DOI などを修正し、［保存］で反映できます。トピック画面からも編集できます。同じトピックの発表で文献情報を共有します。

ページ追加では、上段に白紙・章扉・Reference（参考文献）・Appendix、下段に配置テンプレート4種類（文と図・図と箇条書き・表・2つの比較）を表示します。参考文献とAppendixは、すでにある場合は選択できません。章扉は［章扉］から作成します。参考文献の本文は自動生成し、直接編集しません。文献がスライドの本文領域に収まらない場合は、自動で次のページへ送ります。引用がなければ「引用なし」と表示します。次の囲みや `## 参考文献 {#references}` でも参考文献ページを作れます。参考文献ページがなくても、各ページ下部の引用は表示します。

```markdown
::: {#refs}
:::
```

- **ページの移動**：原稿のブロック表示ではページ番号、下のサムネイルと一覧表示ではページの画像をドラッグして並べ替えます。移動先は線と「○ページの前／後」で表示します。離すと下のサムネイルとOキーの一覧の並びがすぐに変わり、ページの本文は後から自動保存します。原稿欄の上下の端に近づけると自動でスクロールし、端に近いほど速くなります。章扉も1ページとして移動します。Esc で中止でき、移動後は［元に戻す］で取り消せます。
- **二本指の横スワイプ**：編集画面・発表画面では前後のスライドへ1ページずつ移動します。先頭・末尾でもホームへは戻りません。
- **下のサムネイル**：スライド・テーマの編集後は、帯に見えているページから順に更新します。自動検査や書き出しの実行中も更新を続けます。帯の上にはページ番号を表示し、段階表示があるページだけ右に「1 / 3」のように現在の step と総数を追加します。ページ番号の位置は変わりません。
- **原稿側**：左はページ・段落・図・列の囲みが分かるブロック表示です。クリックした部分だけ QMD の入力欄になり、編集できます。ページ番号で折りたたみ、上の［すべての記法を表示］で本文の記法表示に切り替えます。原稿を編集すると、最後の入力から約120ms後に保存され、スライドが更新されます。
  箇条書きの項目が続くところで、次の項目の本文先頭にカーソルを置いて `Delete`（後方削除／Backspace）を押すと、1回目は前の項目内の改行になり、もう1回押すと前の行につながります。
- **本文の改行**：原稿の本文では、空行を挟まない改行を同じブロック内の改行として表示し、空行でブロックを分けます。スライド上の本文編集中は、`Enter` 1回で同じブロック内を改行します（原稿には `\` と改行で保存）。続けてもう1回押して空行を入れると、別のブロックになります。箇条書きでは、従来どおり次の項目を作ります。
- **スライド名**：原稿のブロック表示で、番号の隣の名前をクリックして直接編集できます。Enter または Esc で編集を終え、自動保存します。表紙では見出しを「表紙」と表示し、タイトル欄で名前を編集します。
- **表紙**：原稿のブロック表示の表紙のページは入力欄です。タイトル（`Enter` で改行）・副題・発表者を書きます。発表者は人を足して名前と所属を入れます。所属は任意で、いくつでも入れられ、欄を押すとほかの人の所属が候補に出ます（`Enter` で加える、空の欄で `⌫` で最後の所属を外す、空の欄で `Enter` で次の人へ）。左のつまみか `⌥↑↓` で順番を変えます。同じ所属の人がいると、表紙では名前に `*1` のような印が付き、所属が下にまとまります（全員が同じ所属なら印は付けません）。
- **スライドの表紙**：タイトル・副題は、ほかのページの本文と同じようにスライドで選んで直せます（文字の大きさ・色・揃え・余白も同じ操作）。削除はできず、太字・斜体・リンクはありません。タイトルを直すと、表紙のスライド名と発表の題名（front matter の `title`）も同じ文字になります。発表者の名前・所属の内容は上の表紙の欄で直します。
- **記法表示**：先頭の設定・表紙・自動生成ページは表示しません。タイトル・発表者は表紙の入力欄、テーマはテーマのタブ、目次はブロック表示の「目次」の行のスイッチで設定します。
- **スライド側**：段落の余白・画像・図をクリックするとその中身を選び、列・箱の枠や内側の余白をクリックすると外側の列・箱そのものを選びます。ホバーの枠もクリックで選ばれる範囲を示します。原稿の対応範囲も強調され、原稿のカーソルの位置のブロックも選ばれます。下の帯に選んでいる位置（`p3 › 横並び › 列1 › 段落`）が出て、押すとその層を選びます。枠の色は原稿のブロック表示の線と同じ層の色です。選ぶとブロックの上に小さなツールバー（外側・内側を選択、内側・外側の余白、削除）が出ます。`Esc`、何もない所、スライドの外のクリックで選択を外します。
- **キー**（ブロックを選んでいるとき。原稿のブロック表示で線を選んでいるときも同じ）：`W`／`S` で縦の並びの前・次、`A`／`D` で隣の列（高さの近いブロック）、`Q`／`E` で外側・内側（いちばん外側のブロックで止まります）。`⇧`＋`WASD` で並べ替え（続けて押した分は `⌘Z` 1回で戻る）、`⌥`＋`WASD` で上下に段落・左右に列を足してすぐ書けます（何も書かなければ原稿は変わりません）。`R`／`F` を押している間は内側／外側の余白のつまみになります。`Enter` で編集（囲みなら内側）、`Delete` で削除。矢印は選択中も ↑↓ でページ、←→ で段です。
- **文字**：未選択の段落はクリックで選び、選択枠のある段落の文字付近を押すと、その位置から編集を始め、そのままドラッグして文章を範囲選択できます。選択中の段落や箇条書きの余白をもう一度クリックすると、押した位置に近い行の末尾から文字編集に入ります。余白をドラッグするとブロックを移動できます。編集中は同じ段落の余白を押しても編集を続けます。打った文字はそのまま原稿に反映されます。書式バーの［外側を選択］または `Esc` で段落の選択に戻ります。さらに［外側を選択］で親の囲みや列へ移動できます。1回の編集は `⌘Z` 1回で戻せます。
- **文字の書式**：編集中は文字の上に書式バーが出ます。文字の大きさ（⊖ 数値 ⊕、`⌘]`／`⌘[`）、文字の色（A を押すとテーマの色のメニュー。ほかの色も選べます）、太字・斜体（`⌘B`／`⌘I`）、色と大きさを戻す、の順です。文字を選んでいればその部分に、選んでいなければブロック全体にかかります。色は原稿に `[語]{.accent}` のようにテーマの色の名前で書かれます（`.accent`・`.main`・`.muted`・`.warn`・`.good`）。ボタンの意味は、カーソルを合わせると出ます。
- **表**：1回目のクリックは表全体の選択で、ふつうのブロックと同じように持って動かせます。選んだ表のセルの文字をもう一度クリックすると、そのセルだけをスライド上で直せます。`Tab`／`⇧Tab` や別のセルのクリックで隣へ移り、`Enter` はセル内の改行です。表を選ぶとツールバーで表全体の文字サイズと太字を変えられます。列の境目をドラッグすると列の幅が、右端をドラッグすると表の幅が変わり、文字は列の中で折り返して、増えた分の行は下へ伸びます（境目のダブルクリックで列の幅を元に戻せます）。
- **持って動かす**：選んだブロックの余白を押して少し動かすと持てます。線の位置に置き、下のページの帯に落とすとそのページの最後へ移ります。`Esc` で取り消します。
- **大きさ**：選んだブロックの端のつまみで変えます。画像・HTML図は角、列は左右の辺、箱は下の辺で調整します。
- **属性の重複警告**：原稿内の位置が特定できた警告は、押すと該当ページと原稿の指定箇所を開きます。後の指定は無視されるため、属性を1つにまとめてください。
- **表紙の移動と文字サイズ**：タイトル・副題はブロック本体をつかんで移動できます。動かさずにもう一度押すと文字編集に入り、文字サイズを変更できます。ブロック選択時には文字サイズのメニューを出しません。右下のつまみで幅・高さを変更できます。高さは文字が収まる最低限より小さくなりません。位置の移動は元の配置からの差分で、後ろのブロックの位置は変えません。
- **名前と所属の配置**：スライド上の名前・所属は文字に合う幅の枠で選択し、ひとまとまりでつかんで移動できます。選択時の配置アイコンか、表紙の入力欄の「発表者」の行のアイコンで所属を下・右・左へ切り替えられます。複数人で同じ所属を持つ場合は、所属をまとめる表示を保ったまま位置を変更します。人物・建物アイコンの横の数値で、名前・所属の文字サイズを個別に調整できます。名前・所属ごとにフォント（テーマに合わせる・ゴシック・明朝・等幅）と太字も変更できます。位置・文字サイズ・書式は保存され、取り消しもできます。
- **余白**：内側余白の基本値は通常のブロックで12px、表紙のタイトル・副題で48pxです。文字の上下は、行高や段落由来の空きも含めた値をつまみに表示します（フォントや囲みによって30px前後になる場合があります）。既定の見た目はそのままで、上下を0まで縮められます。複数行の行間は変わりません。表紙は囲みだけに余白を持たせ、中の段落の余白や飾りの間隔を重ねません。文字は囲みの幅から左右の内側余白を引いた領域で折り返します（原稿の明示的な改行は残ります）。ページ全体の左右の余白は別の設定です。ツールバーの内側・外側の余白を押すか、`R`／`F` を押している間、4辺のつまみで調整できます。調整中はツールバーが隠れます。ボタンで開始した調整は `Esc` で終了し、`R`／`F` で開始した調整はキーを離すとツールバーが戻ります。`⇧` で4辺をそろえ、ダブルクリックで個別設定を解除します。外側の余白は既存の間隔に加算されます。
- **段階表示の印**：ブロックを選び、ツールバーの［段階表示］で表示する段を設定できます。本文・図・画像に加え、囲み・列・横並び全体にも設定できます。段 0 は最初から表示します。原稿側・スライド側の数字の丸を押すと、そのブロックの段階表示メニューが開きます。両側とも固定の青で、今のページのまだ出ていない段は白抜きの点線です。印は下の操作バーと同じ通し番号です。最初から表示するHTML図にも「①–③」のように初期状態と途中経過を含む範囲を表示し、後続の番号は自動で繰り上がります。設定メニューは「段番号 → 通し番号」を併記します。配置に関係なく小さい段から表示し、同じ段の要素は同時に表示します。同じ段のHTML図は一緒に進み、最長の図が終わってから次の段へ進みます。
- **画像**：画像を選ぶと、ツールバーの［画像の揃え］を押すたびに、左 → 中央 → 右 → 左と切り替わり、その場で反映します（初期値は中央）。
- **挿入**：スライドでブロックを選んで `/`、または原稿のブロック表示の行頭で `/` を打つと出るメニューから、画像・図（HTML）・数式・表・文献の引用・脚注・コードを入れます。入る位置はカーソルの後です（原稿で入力中ならその段落の後、スライドでブロックを選んでいればその後、どちらもなければ今のページの最後）。数式は打ちながら表示を確かめられ、よく使う形（分数・総和・期待値・行列など）のボタンがあります。表は `Tab` で次のセルへ進み、表計算のセルを貼ると広がります。同梱テーマの表は内容に合う幅で表示し、セルの左右の余白を抑えています。引用は `reference.bib` から選び、文の中（カーソルの所か、選んでいる段落の最後）に `[@key]` を入れます。スライドの数式・表は選んで `Enter`（またはツールバーの鉛筆）で直せます。
- **数式の画面**：上から、書く欄（書いた分だけ広がる）・どう出るか・前に使った数式・雛形の順です。前に使った数式と雛形は最近使った順に横に並び、横に滑らせるか ‹ › で送ります。確定のボタンはなく、外を押すと入って閉じます（`Esc` でやめる）。画面は掴んで動かせ、右下で大きさを変えられます。原稿のブロック表示では、数式は書き始めだけを見せる札になり、押すとこの画面で直せます。欄を空にして閉じると、その数式を消します。`$$` の中で改行すると、スライドでも改行されます（`&` を書いた所で揃います）。
- **前に使ったもの**：数式・画像・図の挿入では、同じトピックの発表（この発表を含む）の原稿で使ったものも選べます。数式は打った所までで候補が絞られ、`Tab`（または `↓` で選んで `←→`・`Enter`）で欄に入れてから直せます。画像と図は、他の発表のものが区切り線の後に並び、選ぶとこの発表にコピーして入ります。候補は保存しておくのではなく、原稿から毎回集めます。
- **貼り付け**：画像を `⌘V` で貼ると、`images/` に保存してカーソルの後に入れます（同じ画像は2回保存しません。幅はスライドに収まる値で入れます）。原稿に表計算のセル（2行2列以上）を貼ると表になります。
- **素材**：原稿の欄の上のタブで［素材］に切り替え、その下の選択（左が HTML、右が画像）で切り替えると、縮小表示で並べます（名前と挿入可否・使用状況を表示）。初期表示は HTML で、以降は最後に選んだ種類を開きます。画像・HTML のカードを押すと大きなプレビューが開き、［閉じる］または Esc で戻れます。図の形式の HTML はプレビュー内のクリックで次のステップへ、左側のクリックで前へ、左側の長押しで最初へ戻ります（トピックの HTML も同じ操作）。［選択］ボタンかカードの長押しで複数選択に入り、削除するときは［選んだ素材を削除］を押します。カードを持ってスライドへ動かすと、線の出た所に入ります（ページの帯へ落とすとそのページの最後）。挿入できる素材には緑の「✓ 挿入可」、現在の発表で使っている素材には別に「使用中」を表示します。図の挿入可否はファイルの形式や依存先の静的検査によるもので、実行時の正常動作を保証するものではありません。図の形式でない HTML は薄く表示され、持って動かせません。理由・使っているページ・トピックか発表専用かは、カーソルを合わせると出ます。画像の追加は末尾の点線のタイル（またはドロップ）。HTML の一覧には追加ボタンを表示しません。図の形式でない HTML は、カードの［AI に図の形式で作り直してもらう］でチャットに指示を足せます。
- **下書き**：原稿の欄の先頭のタブ（ノートとペン）で、発表の下書き（`memo.md`）を項目別の入力欄で書けます。対象読者・想定発表時間・伝えたい結論は本文の上に表示します。本文と一緒にスクロールするので、下へ進むと見えなくなります。対象読者・想定発表時間は「必須」と表示し、未入力なら案内を出します。構成・内容は `## タイトル` ごとに1枚とし、スライドに載せる文をそのまま書きます。［今のスライドの文と図を下書きに反映］では、注釈（`.footnote-small`）の先頭に「＊」を付けます。既存の HTML は `html-図の名前` の1行だけで、現在の発表の topic の図を参照します。未作成ならその次の行から内容・動きを書き、単独の `--` で閉じます。スライド化するときに図は topic の `html/` 内の正式な形式にそろえます。組み直しのメモ・時間配分・【追記】・「言うこと／見せるもの／出典」の作業欄は下書きに入れません。公開範囲の入力はありません。書くと自動で保存します。中身がまだ無い発表（作ったばかりで雛形のまま）を開くと、最初にこのタブが開きます。スライドの中身がある発表では原稿のタブが開きます。このタブを見ている間、右のチャットは「下書きのチャット」になります（下の「AI チャット」）。
- **参考資料**：原稿の欄のフォルダのタブで、その発表の参考資料（`materials/`）を開きます。実験結果のフォルダ・PowerPoint の雛形・論文の PDF など、形式は何でも置けます。操作は VS Code のエクスプローラーと同じです。木の上の［`materials/`］を押すとパソコンのフォルダの画面（Mac は Finder）で開きます。その右の［パソコンからファイルを追加］または［パソコンからフォルダを追加］を1回押すと、OS 標準の選択画面が開きます（ファイルとフォルダは別々に選びます）。［新しいフォルダ］はその場で名前を打って作ります。どちらも選んでいるフォルダの中に入ります。行を押すと選び、ファイルなら木の下に中身が出ます（画像・PDF・テキスト）。ダブルクリックでパソコンのアプリで開きます。`Enter`／`F2` で名前の変更、`Delete`／`⌫` で削除（確かめてから保管フォルダの `.slide-studio/trash/` に移します）、`↑↓` で選択、`←→` でフォルダを閉じる・開く。行を持ってフォルダへ落とすと移ります。パソコンのファイルやフォルダは、落とした場所にそのまま入ります（フォルダは中の構成のまま）。スライドには入りませんが、AI に送る指示に場所と一覧が付き、AI はそれを読んで作業します（変更はしません）。
- **左の欄のタブの切り替え**：数字キーで `1` 下書き・`2` 原稿・`3` 素材・`4` 参考資料・`5` テーマに切り替えます（タブにカーソルを合わせると出ます）。`0` で左の欄を閉じます。文字を入れている欄の中では効かないので、欄の外を押してから使います。左の欄を閉じていれば開きます。キーで下書きを開いたときは、入力欄へは移りません。
- **取り消し・やり直し**：上部のボタン、または `⌘Z`／`⇧⌘Z` を使います。Windows/Linux は `Ctrl` です。
- **別の発表へ**：左上の［ホーム］を押します。保存待ちの入力を保存してから一覧に戻ります。

本文と表のセルはスライド上で直接編集できます。空白や書式の記法の違いによって編集を制限することはありません。閉じていないコードブロックや `:::` があると、そのページ以降は「原文のみ」になります。

外部エディタでの変更も反映されます。未保存の入力と競合した場合は、再読み込みか入力のコピーを選ぶ案内が出ます。開いただけでは原稿を書き換えません。

原稿・下書きの競合でクリップボードに写せなかった場合は、読み直さず全文を選択した欄を出します。手動でコピーしてから、変更を捨てて読み直せます。下書きに既存の公開範囲の行がある場合は、画面に表示せず保存時も残します。ホームの［新しい発表］の［＋］は、原稿と下書きの両方が作ったままの発表があるときだけ隠れます。

## AI チャット

編集画面の右側のチャットから、AI にスライドの修正を頼めます。ホーム右上の［動作環境］には各 AI の状態が表示され、未取得の AI には［インストール］が出ます。チャットの［ダウンロード］からも公式配布版を取得できます。取得後はログインボタンを押してください。Codex（OpenAI。既定）は［ChatGPT でログイン］を押し、OS の既定ブラウザーで契約中のアカウントにログインします。ターミナルでの操作は不要です。初回の準備にはネットワーク接続が必要です。自動準備は macOS・Linux の Apple Silicon / ARM64・x86_64 に対応します。Codex のログインと会話は Slide Studio 専用に保存し、VS Code や通常の Codex の履歴とは分けます。初回は Slide Studio 側でログインしてください。保存先は `~/.config/slide-studio/codex`（変更する場合は `SLIDE_STUDIO_CODEX_HOME`）です。分離前のチャットは画面の履歴を残し、次の送信時に直近の会話を引き継いで新しい会話を始めます。VS Code に既に表示されている古い会話は自動では移動・削除しません。Claude Code は［Claude でログイン］、Antigravity は［Google でログイン］を押し、同じように既定ブラウザーでログインします。ログインが完了すると、［動作環境］の各 AI の状態が「ログイン済み」に変わります。実行ファイルは各社の公式配布元からそのまま取得し、ハッシュを照合して専用保存先の `runtime/` に置きます。ターミナルの CLI は変更しません。ホーム右上の［動作環境］から、AI ごとにバージョンの確認・更新・一つ前のバージョンへの切り替えができ、［自動で更新］にチェックがあれば AI の作業中を避けて自動で更新します。Claude Code は安定版（stable）を追います。ログインは各 CLI 自身が行い、アプリはトークンを読みません。Claude の会話と設定は `~/.config/slide-studio/claude` に保存します（変更する場合は `SLIDE_STUDIO_CLAUDE_HOME`）。Antigravity のログインはターミナルの `agy` と共通です。通常の Claude の履歴・設定は移動・削除しません。分離前の会話は画面に残し、次の送信で内容を引き継ぎます。AI は保管フォルダの中だけを変えられるように起動します。

- **モデルと思考量**：思考量の初期値は、どのモデルでも「中」です。「中」に対応していないモデルでは、そのモデルの既定値を使います。入力欄右下のモデル名を押すと、上段に思考量、中央にモデル名、その下に青い思考量スライダーが出ます。カーソル位置に応じてクリック後の思考量を表示し、クリック・ドラッグ・矢印キーで変更できます。右上の矢印で既定の思考量に戻せます。モデル名から選択一覧へ移り、上部の＋で追加画面に切り替えます。チェックは追加画面だけにあり、一覧に表示するモデルを登録・解除します。チェックを外しても使用中のモデルは変わりません。候補は検索・スクロールでき、モデル名・ID・CLI名の大文字小文字、全角半角、空白・ハイフン・アンダースコアの違いは区別しません。モデル・思考量・確認役は、作業が止まっているときに変更でき、次の送信から使います。モデルを変えても画面の会話と成果物は残り、必要な会話を引き継いで新しいAIセッションで続けます。上限やエラーで止まったら［別モデルで続ける］から選び、［選択したモデルで続ける］を押します。確認役だけが止まった場合は［確認役を選んで続ける］で確認から再開します。選択だけでは実行せず、自動切り替えもしません。親と同じモデルを担当の一覧で選ぶと、その担当のモデル・思考量をチャットへの追従に戻します。使えないAIの案内・添付の＋・コンテキストの円は従来どおりです。
- **添付**：入力欄の［＋］で写真やファイルを、スクリーンショットは貼り付け（`⌘V`）で添付できます。ファイルは送信したときに保存され、写真は発表の `images/`、ほかは `materials/`（参考資料）に置かれます。送らずに外した添付は保存されません。
- **コンテキスト**：送信の横の円が、会話で使っているコンテキストの割合です。カーソルを合わせると、使ったトークン数と、その AI のアカウントの5時間・1週間の上限の使用率とリセットの時刻が出ます。Codex は起動時と実行中に、Claude Code は実行のたびに読むので、Claude Code の上限は最後の実行のときの値です（古いときはそう書きます）。コンテキストも上限も分からない AI では円は出ません。 会話が64,000トークンまたはコンテキスト上限の70%に達した担当は、次の実行で新しい会話に切り替えます。編集担当には直近の会話を最大16,000文字で引き継ぎ、古い会話から送信対象を外します。画面の履歴とファイルは残ります。確認役には今回の確認内容を改めて渡します。429で失敗した担当も、次に実行するときに会話を新しくします（自動再試行はしません）。履歴を減らしても、利用枠や一時的な制限による429が解消するとは限りません。
- **ためてまとめて送る**：入力欄に書いた指示は、表示中のページごとに「未送信の指示」として自動で残ります。ページを見ながら書きためて、送信（↑、`⌘Enter`）でまとめて送ります。送信を押すとすぐ会話欄に指示と「送信しています…」が表示されます。送信が失敗したときは入力と添付が戻ります。指示を押すとそのページへ移り、続きを書けます。最初の説明は、入力を始めると消えます。そのタブの未送信の指示をすべて消すと、送信前なら再び表示します。
- **対象**：［固定］を押すと、その会話の指示先（ページ・図）を保ったまま他のページを閲覧できます。固定中は図を選んでも指示先を変えません。［固定中］を押すと解除し、表示中のページ（選んでいる図）への指示に戻ります。入力欄の上に対象のページ（表示中のページ）が出ます。［全体］で発表全体への指示にします。スライドで図を選ぶとその図への指示になり、余白・本文・チャットなどをクリックしても図への指示を維持します。別のページへ移動すると、移動先のページへの指示に戻ります。横に出る［ページ］でページへの指示に切り替えます。キーは `⌥1` 図・`⌥2` ページ・`⌥3` 発表全体です（ボタンにカーソルを合わせると出ます）。送った指示の対象は、送った後にページを移っても変わりません。
- **タブ**：タブごとに別の会話です。［＋］で新しいタブを開きます。画面を開き直すと新しいタブを表示し、前回のタブは閉じます（実行中のタブは残します）。会話や書きかけは履歴から戻せます。［履歴］にはスライド・下書き・テーマの会話を最近の送信順に並べ、会話名や本文で検索できます。空のタブは履歴に出しません。開いている会話は、薄い背景とタブと同じ色の点、「開いています」で区別します。会話名を押すと続きから再開できます。×で閉じても会話は削除されません。タブは必ず1つ開いています。最後の1つが何も始めていない新しいタブなら×は出ず、会話のある最後のタブを閉じると新しいタブに入れ替わります。タブどうしは同時に作業できます。タブの色は会話名の下線で表示します。AI からの未回答の確認があるタブはオレンジの枠で強調し、タブを開いても回答を送るまで残します。ページの帯の色の点は未送信の指示があるページ（点滅は作業中）です。別タブの未送信通知や、スライド下の指示一覧は表示しません。
- **作業中**：途中経過（コマンド・変更）が出ます。途中経過を開くと、スクロール中も上部にトグルが残り、そこから閉じられます。［止める］で中断できます。作業中は、指示の対象だけをロックします（オレンジで表示）。全体への指示は原稿全体、ページへの指示はそのページ、図への指示はその図です。ほかの部分は作業中も変更できます。
- **終わったら**：スライド・図・テーマのファイルが変わったときだけアプリが検査し（質問に答えただけなど、何も変えなかった送信では検査も確認もしません）、この送信で増えたエラーがあれば同じ会話で AI に直させます（最大3回。チャットに「直しています（1/3）」と出ます）。送信の前からあったエラーは直させず、別の欄に出します。その後、確認役が確かめます。結果には自動修正後の指示ごとの ✓／✗、変更したファイル、最終の検査結果を出します。修正が同じ状態を繰り返す場合は、途中で止めて理由を表示します。3回直させてもエラーが残ったときは［検査結果を添えて再依頼］で、問題を未送信の指示に加えられます（送信は自分で押します）。
- **会話モード**：入力欄の下の吹き出しを押すと、そのタブの送信が会話モードになります（もう一度押すと戻ります）。AI は同じ会話のまま、ファイルを読むだけで変えずに答えます。控え・検査・確認役はなく、スライドの編集もロックしません。相談してから吹き出しを戻して「それで直して」と送れば、会話の内容をふまえて AI が直します。AI は、分からないことや資料に無いデータを推測で埋めず、そう伝えます（会話モードでないときも、分からないまま直すより、直さずに聞きます）。
- **相談役**：編集している AI は、作業の途中で迷ったとき `slide-studio consult` で相談役（別の会話の AI。読むだけでファイルは変えない）に質問できます。相談役への指示は、置き場の AGENTS.md のほかは送られた質問だけです。質問と答えはチャットに残り、相談役の会話もタブごとに続きます。既定はオフで、［サブエージェント］の［相談役］の行でオンにすると使えます。AI・思考量も同じ行で選べます（未設定ならチャットに追従）。
- **判断が必要な箇所**：原文から判断できる修正はAIが自動で行い、解消済みの指摘は警告に残しません。利用者の判断が必要な文は `【要判断】` で始め、チャットだけにオレンジで表示します。判断を求める質問は memo.md の本文や設定欄には書き込みません。自動修正で解決できなかった問題や実行エラーは引き続き表示します。
- **確認役との分担**：構造・参照先・構文・重なり・はみ出しなどはアプリが検査し、確認役には結果を渡します。確認役はそれらの再検査をせず、依頼どおりか、説明が整合しているか、読みやすいかを判断します。
- **Appendix**：補足が必要な場合だけ置きます。空の末尾Appendixは削除でき、自動では追加されません。
- **監査ツール**：`slide-studio audit run <発表名>` で全ページ・全stepの画像と問題を取得し、`audit review <発表名> <監査ID> --file <確認JSON>` で所見を記録、`audit status <発表名> <監査ID>` で記録が最新版に対応するか調べます。チャットの確認役は使いません（重なり・はみ出しはアプリの検査が見て、確認役は見た目と文章を判断します）。ツールの定義は `slide-studio audit tools` で取得できます。
- **戻す**：未送信の指示を消しても、チャットの中の ⌘Z で戻せます。チャットの ⌘Z とスライドの ⌘Z は別々の履歴を戻します。［この送信の前に戻す］で、その送信で変わったファイルだけを元に戻します（新しく作られた図は消え、消されたファイルは戻ります）。発表・トピック・テーマの外で変わったファイルは戻さず、一覧に出します。参考資料（`materials/`）は大きいことがあるので控えを取らず、変わっても戻しません（一覧には出ます）。
- **テーマのチャット**：左の［テーマ］タブを見ている間は、対象を選ばず今のテーマの変更を頼めます。返事は普通の文章で、終了後はテーマだけを検査します。同じテーマでも複数のチャットタブから並行して指示を送れます。作業中もスライドは編集でき、［この送信の前に戻す］で戻るのは送信時のテーマ CSS だけです。同じテーマを使う他の発表にも変更が反映されます。
- **下書きのチャット**：左の欄で［下書き］を見ている間は、チャットが「下書きのチャット」に切り替わります（上に表示が出ます）。スライドのチャットとは別のタブ・会話で、ページや全体の区別はなく、書いて送る（`⌘Enter`）とすぐ AI が答えます。相談には答えだけを返し、頼むと下書き（`memo.md`）を書き換えます。原稿は読むだけで変えません。返事は普通の文章で、検査はなく、作業中もスライドは編集できます。［この送信の前に戻す］で戻るのは下書きだけです。AI が下書きを変えたときは、返事の下の［下書きの変わった所］で差分を見られます。AI への決まりごとは保管フォルダの `.agents/skills/slide-studio-memo/SKILL.md` に書いてあり、自分で書き換えられます。
- **下書きからスライドにする**：下書きのチャットで「スライドにして」と頼むと、［スライドを作る］と［まだ下書きを続ける］の確認ボタンが出ます。自動では起動せず、［スライドを作る］を押したときだけ、スライドのチャットの「下書きから」タブで作り始めます（新規タブには確認役の設定も引き継ぎ、以後は同じタブで会話が続きます）。既にスライドがあるときは、前回スライドにしてから下書きが変わった所だけを反映し、手で直した所は残します。全部作り直したいときは「作り直して」と頼みます。下書きの確認で直す所が見つかったときは止まり、指摘の下のボタンで、そのままスライドにすることもできます。

編集画面で `F` を押すと今のページ・段階から全画面で発表を開始し、`Shift+F` では最初から開始します。`Esc` で編集画面に戻ります。文字入力中はこれらのショートカットは動作しません。

## 書き出し

編集画面で `P` を押すか、右上の［書き出し］を押すと、HTML／PDF を選ぶパネルが開きます（文字入力中は `P` のショートカットは動作しません）。［HTML］または［PDF］を押すと、その形式で書き出します。処理中は進行状況をバーで表示し、完了すると選んだファイルのダウンロードを自動で開始します。保存先はブラウザの設定に従います（通常は「ダウンロード」フォルダ）。画面のボタンから再ダウンロードもできます。保存待ちの原稿を先に保存し、全ページを検査してから書き出します。検査でエラーがあれば問題を画面に表示し、書き出しを止めます。

HTML は図のアニメーションを含む単一ファイルです。PDF には、各ページの最後の step の状態を1枚ずつ出力します。途中の step で表示した要素が後で消えたり置き換わったりする場合は、その step を表示してスライドの下の操作バーの step 数の右にあるチェック（ツールチップ「PDF に入れる」）を入れると、その step の状態も PDF に入ります。印は原稿の見出しに `pdf="2 4"` の形で保存されます（番号は操作バーの表示と同じ 1 始まり）。図の step 数が減って番号がなくなると、検査で警告します。step は、伝えるメッセージが変わるところや、画面・場面が切り替わるところで区切ります。独立した説明のない細かな動きは図の `transition` にまとめ、途中のフレームは PDF に含めません。既存の図に細かな step が多い場合は、その区切りを整理してください。HTML の step 移動は、通常はアニメーション付き、連続操作（300ms以内）や図の再生途中の操作では移動先の確定状態をすぐ表示します。操作を止めたあとに演出が溜まって再生されることはありません。ファイル名は日本語の発表タイトルに `.html`・`.pdf` を付けた名前です。ファイル名に使えない記号は `_` に置き換えます。生成したファイルは発表フォルダにも保存されます。書き出し後に編集した場合は、もう一度書き出してください。

## 保存場所

初回に選んだフォルダに保存します。`~/Slides` は候補で、名前と場所は自由です。アプリのソースコードとは別の場所を使います。実際の保存場所は、ホーム右上の［動作環境］から確認できます。

ホームの［保管場所を切り替える］から、新しいフォルダの作成・既存フォルダの選択・最近開いた場所への切り替えができます。選んだフォルダの直下に `decks/`・`topics/`・`themes/`・管理用の `.slide-studio/` などを作成します。既存のフォルダは、空のフォルダか Slide Studio の保管フォルダを選べます。切り替えても元のフォルダは残ります。別の画面で切り替え前の保管場所を開いていた場合は、再読み込みしてから編集を続けてください。

選択した場所と最近開いた場所は `~/.config/slide-studio/location.json` に記録し、次回の起動時にも使います。`SLIDE_STUDIO_HOME` または `--root` でも指定できます。古い保管フォルダや旧環境変数は自動参照しません。

```text
<選んだ保管フォルダ>/
├── README.md             # 単独利用の説明
├── build.py              # アプリなしでのコンパイル
├── decks/<発表名>/
│   ├── slides.qmd        # 原稿
│   ├── memo.md           # 下書き
│   ├── styles/           # 発表の CSS
│   ├── materials/        # 参考資料（実験結果・雛形など。形式は自由）
│   ├── <発表名>.html     # 書き出した HTML
│   └── <発表名>.pdf      # 書き出した PDF
├── topics/<トピック名>/  # トピック（同じトピックの発表で共有する）
│   ├── html/             # 図・HTML（_lib/ は図どうしで共有する部品）
│   ├── images/           # 画像（貼り付け・素材から追加したもの）
│   └── reference.bib     # 文献
├── themes/               # テーマ
└── .slide-studio/                  # 同梱の変換コード・ランタイム、内部状態・検査結果
```

**開発途中です。** 図の専用編集画面、他のトピックからの図の挿入は未実装です。開発用のCLI・設定・テストは [開発ガイド](CONTRIBUTING.md) にまとめています。



同梱テーマの serif は terracotta に交代しました。未編集の旧 serif は控えを残して一覧から外し、使用中の発表の参照と選択履歴も terracotta に移します。以後 serif は補充しません。編集済みの独自 serif は保持します。

同梱テーマの sage は廃止しました。起動時に CSS と使用中の原稿の控えを残して一覧から削除し、発表と選択履歴を default に切り替えます。
